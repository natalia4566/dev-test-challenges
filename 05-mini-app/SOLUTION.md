Project Overview

This challenge was completed as a simple fullstack mini application that allows users to search data using a public API, store the results, and display previous searches.

The project demonstrates API consumption, state management, and data persistence using localStorage.

Repository

The full solution for this challenge can be found in the following repository:

https://github.com/natalia4566/challenge-05-mini-app

Features Implemented
-User input to search data (GitHub username)
-API request to GitHub Users API
-Dynamic display of fetched results
-Storage of results in localStorage
-Display of search history
-Simple and clean component-based structure

API Used
GitHub Users API:
https://api.github.com/users/{username}

Technical Approach

The application was built using React with Vite. The main logic includes:
-Handling user input through controlled components
-Fetching data using fetch and async/await
-Updating state with React hooks
-Persisting data in localStorage
-Rendering a history list from stored data
